# Portfólio pessoal — HTML, CSS e JavaScript

## Como abrir

1. Extraia o arquivo ZIP para uma pasta.
2. Mantenha `index.html`, `styles.css` e `script.js` juntos na mesma pasta.
3. Abra `index.html` no navegador. Não é necessário instalar nada nem iniciar um servidor.

## O que editar

- `index.html`: textos, nome, informações, projetos e campos de links/contato.
- `styles.css`: cores, fontes, espaçamentos e adaptação para celular.
- `script.js`: filtros interativos dos projetos.

O site mantém “Seu Nome” e os campos de arte/contato como espaços reservados para você personalizar. As fontes Google Fonts precisam de internet; sem conexão, o navegador usa fontes alternativas locais.
